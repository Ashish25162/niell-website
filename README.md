## 🌐 Deploy to Vercel (100% Free Forever)

1. Create a free account at [Vercel](https://vercel.com).
2. Push this folder to your GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of NIELL Spoken English website"
   git branch -M main
   # Add your remote repo and push:
   # git remote add origin https://github.com/your-username/niell-english.git
   # git push -u origin main
   ```
3. In Vercel, click **"Add New Project"** -> import your GitHub repository.
4. Click **"Deploy"**. Your website will be live in 60 seconds with a free `.vercel.app` URL and free SSL!

## 🎯 How to Connect Your Custom Domain on Vercel
1. Buy your domain (e.g., `niellenglish.com` or `niellclasses.in`) from Namecheap or GoDaddy.
2. In Vercel, go to **Settings > Domains**.
3. Add your domain name.
4. Copy the two DNS records (CNAME and A record) provided by Vercel into your domain registrar's DNS settings.
