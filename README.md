## 🌐 Deploying to Vercel & Connecting `niell.in`

1. Go to **[vercel.com](https://vercel.com)** and sign in with GitHub.
2. Click **"Add New..."** → **"Project"** → import `Ashish25162/niell-website`.
3. Click **"Deploy"**.
4. Once deployed, navigate to **Settings → Domains** and add `niell.in` (and `www.niell.in`).
5. In your domain registrar (where you bought `niell.in`), add these two DNS records:
   * **A Record:** `@` points to `76.76.21.21`
   * **CNAME Record:** `www` points to `cname.vercel-dns.com`
6. Vercel will automatically verify the records and provision a free SSL certificate within 10–15 minutes!
